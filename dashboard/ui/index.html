THE WORKFLOW

From code change
to a reviewed correction.

  1. Run a check.

    In your repository, compare two committed versions with the DocMend CLI, or run Documentation drift in GitHub Actions.

    docmend check --repo /path/to/repo \
  --base BASE_SHA --head HEAD_SHA
  2. Open the report here.

    Import report.json from the output directory or downloaded Actions artifact. Your file is read locally and is not uploaded. Reports reset when you reload.

  3. Follow the evidence.

    Inspect the source contract, the diagnosis and the exact before-and-after text. "Matches code" refers to a checked declaration, not all surrounding prose.

  4. Review, then apply locally.

    Download a proposed patch, or use the CLI’s guarded apply command with the original report. This viewer never changes your repository or creates a pull request.

    docmend apply --repo /path/to/repo \
  --report /path/to/report.json
