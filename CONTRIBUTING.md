# Contributing

DocMend is proprietary software owned by Teyrin. It is not open source.

## Outside contributions

Teyrin does not accept unsolicited pull requests, patches or code. Pull
requests from people outside Teyrin may be closed without review.

If Teyrin invites you to contribute, you must first sign Teyrin's contributor
agreement. By submitting any contribution, you:

- confirm that you wrote it, or have the right to submit it, and that it does
  not include third-party code under terms incompatible with this licence;
- assign to Teyrin all rights, title and interest in the contribution, or,
  where assignment is not possible, grant Teyrin a perpetual, worldwide,
  irrevocable, royalty-free, exclusive licence to use, change, sublicense and
  distribute it for any purpose;
- receive no right to use DocMend in return.

## Issues

You may report bugs or security problems. Reporting does not grant any right
to use the software. For security problems, follow [SECURITY.md](SECURITY.md).
